# <项目> 的规矩

- 测试只用 `ci/accept`：不带参数跑全部阶段，`ci/accept --stage <名>` 跑一个；每阶段退出码 0 通过、77 跳过，最后一行是结论。阶段和判据看 `ci/accept --list`。
- 派生文件只放 `.build/`；写到别处，验收判失败。
- 用例来自真实 bug：修一个 bug，就在 <用例目录> 加一个能复现它的用例，写清 why。
- 不能改的：<列出，例如"ORT 是用户侧，不改">。
- 分支：agent 在 `wip/<id>` 上干活、推中枢；main 只由协调器在验收全绿后推；GitHub 只收 main，由人推。
